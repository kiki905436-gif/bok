# Bok v0.1 自用版 PRD

## 目标

让第一位用户无需重复解释背景，就能快速记录、安静沉淀、可靠找回并继续当前工作。Bok 不是新的聊天客户端，而是多个 AI 共用的本地长期记忆层。

## 核心原则

- Markdown 是唯一事实源。
- 普通记忆默认自动、可见、可撤销。
- 重要记忆不阻断工作，但未经确认不得修改正式内容。
- 模型离线时先本地排队，恢复后再处理。
- 数据位置与模型位置独立。
- Local Only 从网络层禁止外发，不做静默云端降级。
- 检索只给最小必要段落，并返回来源。

## 主要任务

1. 一秒内记录随手记，不填写标题、分类或标签。
2. 聊天客户端把每轮事件先交给 Bok；收据接口立即返回，是否形成长期记忆由后台判断。
3. Bok 后台调用本地大模型判断忽略、新建、更新或冲突。
4. 普通高置信记忆自动提交；重要项目进入“需要关注”。
5. 提问时得到 3～6 个相关段落、来源和 Token 估算。
6. 打开“今天”即可看到当前项目、下一步、待关注和最近自动操作。
7. 任何写入都能回退，外部并发修改不会被覆盖。

## 完成条件

- 随手记、采集队列、记忆收件箱、搜索、引用、项目续接、编辑、移动、回收、版本、备份和恢复均有 API。
- Provider 契约完成“采集→判断→普通自动保存 / 重要记忆待处理”闭环；自动测试使用模拟 Provider，不以用户本地模型的性能或输出质量作为验收依据。
- macOS/Windows 有无依赖启动脚本，核心只使用 Python 标准库。
- 自动测试覆盖权限、冲突、回滚、Local Only、幂等、Token 预算和 API 认证。
- 自动测试覆盖逐轮收据、崩溃补投、外部引用/临时会话/不记忆隔离和原文保留期。
- 现有 UI 的 HTML、CSS、JavaScript 和视觉不因本轮内核开发而改变；允许在预览后端增加不暴露 Token、复用同一业务内核的同源 bridge。

## 非目标

- 完整插件市场。
- 团队协作与组织权限。
- 支付系统。
- 原生移动端。
- Canvas 和公开发布。
- 完整复制 Obsidian。

## 北极星指标

用户不重新解释背景，从 Bok 恢复真实项目并完成下一步的成功次数。
