# Contributing to Bok

Thank you for helping improve Bok.

## Before opening a pull request

1. Keep Markdown as the knowledge source of truth.
2. Do not commit personal vaults, Personal Core data, credentials, local paths, `.bok` runtime state, backups, or generated installers.
3. Keep loopback APIs authenticated and local by default.
4. Add contract tests for changes to memory, authorization, forgetting, recovery, privacy, or native bridges.
5. Run the commands documented in the root README.

Please keep changes focused and explain the user-facing behavior, compatibility impact, and validation performed. By contributing, you agree that your contribution is licensed under Apache-2.0.

# 参与 Bok 开发

感谢你帮助改进 Bok。

提交 Pull Request 前请确认：

1. Markdown 始终是知识事实源。
2. 不提交私人 Vault、Personal Core、凭证、本机路径、`.bok` 运行状态、备份或生成的安装包。
3. loopback API 默认保持认证与本机边界。
4. 修改记忆、授权、遗忘、恢复、隐私或原生桥接时补充合同测试。
5. 运行根目录 README 中列出的测试命令。

请让改动保持聚焦，并说明用户体验变化、兼容性影响和实际验收结果。提交贡献即表示同意以 Apache-2.0 许可发布该贡献。
