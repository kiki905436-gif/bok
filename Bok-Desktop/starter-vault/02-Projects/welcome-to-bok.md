# 第一次使用 Bok

## 一句话结论

从真实任务开始，比先导入一堆资料更容易得到一个有用的第二大脑。

## 适用场景

第一次打开 Bok，或准备把一个持续项目交给 Agent 续接。

## 关键决策

- Starter Vault 只提供最小示例，不包含任何原作者个人信息。
- 正式内容始终保存在本机 Markdown。
- 低风险理解安静形成，敏感和冲突判断保留人工边界。

## 可复用方法

1. 用随手记写下一条真实想法。
2. 对 Agent 说“把我现在最重要的项目整理成项目卡”。
3. 工作结束时说“记录当前进度，下次接着做”。
4. 错误理解在“关于我”中纠正或彻底忘记。
