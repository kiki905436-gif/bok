# Agent 衔接状态

## 一句话结论

Agent 必须同时加载本 Vault 的 `AGENTS.md` 和 Bok 的本机 MCP，才会在每个用户原生回合静默观察、按需取回个人理解；仅能读取 Markdown 不代表自动记忆已启用。

## 最省事的连接方式

1. 在 Bok 中打开“记忆工作台 → 设置”。
2. 点击“一键连接 Codex”。
3. 完全退出 Codex，重新打开，并把本 Vault 作为工作区。
4. 新建一个任务；旧任务不会热加载刚注册的 MCP。

## Agent 自检

- 当前任务能看到 `bok_observe_conversation`：自动观察入口已加载。
- 当前任务能看到 `bok_person_context`：可按任务最小读取已经形成的个人理解。
- 看不到这些工具：只能使用当前 Vault 的通用 Markdown，不能声称已经写入 Personal Core。
- 附件、网页、他人资料必须标成外部来源；密码、密钥、身份或客户隐私不进入长期记忆。

## 体验边界

普通、低风险、高置信习惯会安静积累并可撤销；身份、长期目标、授权、敏感、冲突和低置信判断才进入“需要我介入”。连接过程不改变 Markdown 唯一事实源，也不会把整个 Vault 上传到云端。
